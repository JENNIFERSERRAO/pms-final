# Password Management System 🔐

A secure password management system developed as part of my Master's in Enterprise & IT Security.  
This project demonstrates **secure architecture, authentication flows, and breach detection** using modern security tools and frameworks.

## 🔹 Features
- Strong password generation with complexity rules (length, symbols, entropy).
- Authentication workflow with secure password handling.
- Breach detection by integrating the **Have I Been Pwned API**.
- API testing and validation using **Postman**.
- Threat modeling using **STRIDE**.
- Static code analysis with **SonarQube** and **Bandit**.
- Risk modeling with **IriusRisk**.

## 🔹 Tools & Frameworks
- Python  
- Postman (API Testing)  
- Have I Been Pwned API  
- SonarQube, Bandit  
- IriusRisk  
- STRIDE, OWASP, NIST CSF 2.0  

## 🔹 Key Outcomes
- Implemented a secure authentication flow aligned with **OWASP password policies**.  
- Integrated external API for breach detection of leaked credentials.  
- Identified vulnerabilities early with automated **static code analysis**.  
- Designed security architecture and documented risks using STRIDE & IriusRisk.
